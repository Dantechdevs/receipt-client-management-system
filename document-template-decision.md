# Document Template Decision

## Base template: RESCO HOME LTD style (Image #4)
Navy/orange split header, QTY/DESCRIPTION/PRICE/AMOUNT table,
amount-in-words line, dual signature blocks, diagonal accent.
Use this as the single visual base for Invoices, Receipts, and Quotes
(swap only the title word: INVOICE / RECEIPT / QUOTATION).

## Type-specific additions
- Quotations only: add disclaimer line (from First Landing template)
  "This is a quotation, not a tax invoice. Valid until [date]."
- Receipts only: add footer line (from Elite Stores template)
  "Goods once sold are not re-accepted."
- Invoices/Quotes: optional Subtotal -> Tax/VAT -> Total breakdown,
  with VAT toggle available per line item, not just per document.

## Agreements: kept separate
Plain black-and-white legal format (Services Agreement style):
numbered clauses, checkboxes for payment method, blank signature
lines. No shared branding with invoices/receipts/quotes.
